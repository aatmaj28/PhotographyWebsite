Darkroom Keys

This portal commits straight to your GitHub repo. It needs a fine-grained personal access token — it will be stored only in this browser.

  1. Open github.com → Settings → Developer settings → Fine-grained tokens
  2. Name it e.g. photo-admin, set a long expiration
  3. Repository access → Only select repositories → pick this repo
  4. Permissions → Repository permissions → Contents → Read and write
  5. Generate, copy, paste below
